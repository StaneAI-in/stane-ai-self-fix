                                          Sync phone and laptop

                                          Tasks, fixed tasks, streaks, crossed days and English notes are synced through your private GitHub repository. Videos are never uploaded; each video stays only on the device where you added it.

                                          How to get the token

                                          1. Open GitHub and sign in to your personal account.
                                          2. Go to Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens, and choose Generate new token.
                                          3. Set Resource owner to StaneAI-in. Under Repository access choose "Only select repositories" and pick stane-ai-self-fix-data.
                                          4. Under Permissions, Repository permissions, set Contents to "Read and write". Leave everything else as it is.
                                          5. Generate the token, copy it, and paste it on this page. Do the same on your phone.

                                          The token is saved only in this browser. When it expires, sync stops until you paste a new one; your data on this device is not affected.
